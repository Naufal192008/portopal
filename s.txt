Berikut adalah daftar **Username** dan **Password** untuk login ke aplikasi kasir restoran yang sudah dibuat. Data ini diambil dari tabel `user` yang ada di file `database.sql`.

| No | Username | Password | Role | Hak Akses |
|---|---|---|---|---|
| 1 | `admin` | `admin123` | Administrator | Semua fitur (Entri Meja, Entri Barang, Entri Order, Generate Laporan) |
| 2 | `waiter1` | `waiter123` | Waiter | Entri Barang, Entri Order |
| 3 | `kasir1` | `kasir123` | Kasir | Entri Transaksi, Generate Laporan |
| 4 | `owner1` | `owner123` | Owner | Generate Laporan |

---

### Cara Login

1. Buka browser, akses: `http://localhost/kasir_restoran/`
2. Masukkan salah satu **Username** dan **Password** dari tabel di atas.
3. Klik tombol **Login**.

---

### Catatan Penting

Jika login **gagal** atau muncul pesan error, kemungkinan penyebabnya adalah:

1. **Database belum di-import.** Pastikan Anda sudah menjalankan seluruh isi file `database.sql` di phpMyAdmin. Periksa apakah tabel `user` sudah berisi 4 baris data di atas.
2. **Password di database berbeda.** Jika Anda sebelumnya sudah pernah membuat tabel `user` dengan password lain, jalankan query berikut di phpMyAdmin untuk mengisi ulang datanya:

```sql
USE db_kasir_restoran;

DELETE FROM user;

INSERT INTO user (namauser, password, role) VALUES 
('admin', 'admin123', 'administrator'),
('waiter1', 'waiter123', 'waiter'),
('kasir1', 'kasir123', 'kasir'),
('owner1', 'owner123', 'owner');
```

3. **Nama database berbeda.** Cek file `config/Database.php`, pastikan `$db_name = "db_kasir_restoran";` sesuai dengan nama database yang Anda buat.

---

### Cara Menguji Setiap Role

Setelah login, perhatikan **sidebar menu** di sebelah kiri. Menu yang muncul akan berbeda tergantung role:

- **Login sebagai `admin`**: Akan muncul menu **Dashboard, Entri Meja, Entri Barang (Menu), Entri Pelanggan, Entri Order, Generate Laporan**.
- **Login sebagai `waiter1`**: Akan muncul menu **Dashboard, Entri Barang (Menu), Entri Pelanggan, Entri Order**. Menu Entri Meja dan Laporan **tidak muncul**.
- **Login sebagai `kasir1`**: Akan muncul menu **Dashboard, Entri Transaksi, Generate Laporan**. Menu lainnya **tidak muncul**.
- **Login sebagai `owner1`**: Hanya muncul menu **Dashboard, Generate Laporan**. Menu lainnya **tidak muncul**.

Jika Anda mencoba mengakses URL secara paksa (contoh: login sebagai `waiter1` lalu ketik `http://localhost/kasir_restoran/form_meja.php` di address bar), maka aplikasi akan menolak dan menampilkan pesan **"Anda tidak memiliki akses ke halaman ini."** Ini membuktikan bahwa sistem hak akses berjalan dengan benar.
