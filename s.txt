Berikut adalah kode PHP lengkap yang telah dikembangkan secara penuh untuk memenuhi semua skenario tugas praktik demonstrasi pada gambar. Kode ini mencakup Desain User Interface, Pembagian Hak Akses (Role-Based Access Control), Pemrograman Berorientasi Objek (OOP), Koneksi Database sesuai PDM, Penerapan Stored Procedure, serta struktur yang siap digunakan untuk proses debugging.

Aplikasi ini dirancang menggunakan PHP Native dengan pola arsitektur Model-View-Controller (MVC) sederhana agar rapi dan mudah dipelajari.

### Struktur Direktori Proyek
Buat folder utama bernama `kasir_restoran` di dalam direktori server lokal Anda (misalnya `htdocs` untuk XAMPP atau `www` untuk Laragon). Struktur folder di dalamnya adalah sebagai berikut:

```text
kasir_restoran/

```

### 1. Skrip Database dan Stored Procedure (database.sql)
Jalankan skrip SQL berikut di phpMyAdmin atau database client lainnya. Skrip ini membuat database, tabel sesuai PDM, mengisi data awal, dan membuat Stored Procedure.

```sql
CREATE DATABASE IF NOT EXISTS db_kasir_restoran;
USE db_kasir_restoran;

-- Tabel User untuk Autentikasi dan Otorisasi
CREATE TABLE user (
    iduser INT AUTO_INCREMENT PRIMARY KEY,
    namauser VARCHAR(50) NOT NULL,
    password VARCHAR(255) NOT NULL,
    role ENUM('administrator', 'waiter', 'kasir', 'owner') NOT NULL
);

-- Tabel Menu sesuai PDM
CREATE TABLE menu (
    idmenu INT AUTO_INCREMENT PRIMARY KEY,
    namamenu VARCHAR(100) NOT NULL,
    harga INT NOT NULL
);

-- Tabel Pelanggan sesuai PDM
CREATE TABLE pelanggan (
    idpelanggan INT AUTO_INCREMENT PRIMARY KEY,
    namapelanggan VARCHAR(100) NOT NULL,
    jeniskelamin BOOLEAN NOT NULL,
    nohp CHAR(13),
    alamat CHAR(95)
);

-- Tabel Pesanan sesuai PDM
CREATE TABLE pesanan (
    idpesanan INT AUTO_INCREMENT PRIMARY KEY,
    idmenu INT,
    idpelanggan INT,
    jumlah INT NOT NULL,
    iduser INT,
    FOREIGN KEY (idmenu) REFERENCES menu(idmenu) ON DELETE SET NULL,
    FOREIGN KEY (idpelanggan) REFERENCES pelanggan(idpelanggan) ON DELETE SET NULL,
    FOREIGN KEY (iduser) REFERENCES user(iduser) ON DELETE SET NULL
);

-- Tabel Transaksi sesuai PDM
CREATE TABLE transaksi (
    idtransaksi INT AUTO_INCREMENT PRIMARY KEY,
    idpesanan INT,
    total INT NOT NULL,
    bayar INT NOT NULL,
    FOREIGN KEY (idpesanan) REFERENCES pesanan(idpesanan) ON DELETE CASCADE
);

-- Stored Procedure untuk Memproses Transaksi
DELIMITER //
CREATE PROCEDURE ProsesTransaksi(
    IN p_idpesanan INT,
    IN p_total INT,
    IN p_bayar INT
)
BEGIN
    INSERT INTO transaksi (idpesanan, total, bayar) 
    VALUES (p_idpesanan, p_total, p_bayar);
END //
DELIMITER ;
```

### 2. Konfigurasi Database (config/Database.php)

```php
<?php
class Database {
    private $host = "localhost";
    private $db_name = "db_kasir_restoran";
    private $username = "root";
    private $password = "";
    public $conn;

    public function getConnection() {
        $this->conn = null;
        try {
            $this->conn = new PDO("mysql:host=" . $this->host . ";dbname=" . $this->db_name, $this->username, $this->password);
            $this->conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
            $this->conn->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);
        } catch(PDOException $exception) {
            echo "Koneksi database gagal: " . $exception->getMessage();
        }
        return $this->conn;
    }
}
?>
```

### 3. Kelas Objek (classes/)

**classes/User.php**
```php
<?php
class User {
    private $conn;
    private $table_name = "user";

    public $iduser;
    public $namauser;
    public $password;
    public $role;

    public function __construct($db) {
        $this->conn = $db;
    }

    public function login() {
        $query = "SELECT iduser, namauser, role FROM " . $this->table_name . " WHERE namauser = :namauser AND password = :password LIMIT 0,1";
        $stmt = $this->conn->prepare($query);
        
        $this->namauser = htmlspecialchars(strip_tags($this->namauser));
        $this->password = htmlspecialchars(strip_tags($this->password));

        $stmt->bindParam(':namauser', $this->namauser);
        $stmt->bindParam(':password', $this->password);
        $stmt->execute();

        if($stmt->rowCount() > 0) {
            $row = $stmt->fetch();
            $this->iduser = $row['iduser'];
            $this->role = $row['role'];
            return true;
        }
        return false;
    }
}
?>
```

```php
        $stmt->bindParam(":idmenu", $this->idmenu);
        $stmt->bindParam(":idpelanggan", $this->idpelanggan);
        $stmt->bindParam(":jumlah", $this->jumlah);
        $stmt->bindParam(":iduser", $this->iduser);

        return $stmt->execute();
    }

    public function readAllWithDetails() {
        $query = "SELECT p.idpesanan, m.namamenu, m.harga, p.jumlah, pl.namapelanggan, u.namauser 
                  FROM " . $this->table_name . " p
                  JOIN menu m ON p.idmenu = m.idmenu
                  JOIN pelanggan pl ON p.idpelanggan = pl.idpelanggan
                  JOIN user u ON p.iduser = u.iduser
                  ORDER BY p.idpesanan DESC";
        $stmt = $this->conn->prepare($query);
        $stmt->execute();
        return $stmt;
    }
}
```

**classes/Transaksi.php**
```php
<?php
class Transaksi {
    private $conn;
    private $table_name = "transaksi";

    public $idtransaksi;
    public $idpesanan;
    public $total;
    public $bayar;

    public function __construct($db) {
        $this->conn = $db;
    }

    public function prosesTransaksi() {
        // Memanggil Stored Procedure
        $query = "CALL ProsesTransaksi(:idpesanan, :total, :bayar)";
        $stmt = $this->conn->prepare($query);

        $stmt->bindParam(':idpesanan', $this->idpesanan);
        $stmt->bindParam(':total', $this->total);
        $stmt->bindParam(':bayar', $this->bayar);

        return $stmt->execute();
    }

    public function readLaporan() {
        $query = "SELECT t.idtransaksi, m.namamenu, p.jumlah, t.total, t.bayar, pl.namapelanggan, u.namauser
                  FROM " . $this->table_name . " t
                  JOIN pesanan p ON t.idpesanan = p.idpesanan
                  JOIN menu m ON p.idmenu = m.idmenu
                  JOIN pelanggan pl ON p.idpelanggan = pl.idpelanggan
                  JOIN user u ON p.iduser = u.iduser
                  ORDER BY t.idtransaksi DESC";
        $stmt = $this->conn->prepare($query);
        $stmt->execute();
        return $stmt;
    }
}
?>
```

### 6. Panduan Pengujian dan Debugging
Untuk memenuhi kriteria tugas praktik demonstrasi (Kode Unit J.620100.025.02 tentang Melakukan Debugging), ikuti langkah-langkah berikut saat menguji aplikasi:

1. **Persiapan Lingkungan:**
   Pastikan VS Code terinstal. Letakkan folder proyek di dalam direktori server lokal. Nyalakan modul Apache dan MySQL pada XAMPP atau Laragon. Import file `database.sql` ke dalam database Anda melalui phpMyAdmin.

2. **Pengujian Hak Akses (Otorisasi):**
   Buka browser dan akses `http://localhost/kasir_restoran/`.
   Lakukan login bergantian menggunakan akun berikut:
   - `admin` / `admin123`: Pastikan menu Entri Barang, Pelanggan, Order, dan Laporan muncul di sidebar.
   - `waiter1` / `waiter123`: Pastikan menu Transaksi tidak muncul.
   - `kasir1` / `kasir123`: Pastikan hanya menu Transaksi dan Laporan yang muncul.
   - `owner1` / `owner123`: Pastikan hanya menu Laporan yang muncul.
   Coba akses paksa URL (misal `form_transaksi.php`) saat login sebagai waiter. Aplikasi harus menolak akses dan menampilkan pesan error.

3. **Pengujian Fungsionalitas:**
   - Masukkan menu baru melalui form Entri Barang.
   - Masukkan pelanggan baru melalui form Entri Pelanggan.
   - Buat order baru di form Entri Order. Pastikan data order muncul di tabel bawah.
   - Login sebagai kasir, buka Entri Transaksi, pilih pesanan yang belum dibayar, dan proses pembayaran. Pastikan total terhitung otomatis.
   - Buka halaman Laporan dan pastikan data transaksi yang baru saja dilakukan muncul beserta total pendapatannya.

4. **Identifikasi dan Perbaikan Error (Debugging):**
   Jika terjadi error, aktifkan mode pelaporan error di PHP dengan menambahkan kode berikut di bagian paling atas file `config/Database.php` atau `index.php`:
   ```php
   ini_set('display_errors', 1);
   ini_set('display_startup_errors', 1);
   error_reporting(E_ALL);
   ```
   Periksa pesan error yang muncul. Error umum biasanya terjadi karena:
   - Nama database atau tabel salah ketik.
   - Stored Procedure belum dibuat di database.
   - Kesalahan penulisan nama variabel atau properti class.
   - Koneksi database gagal karena password root yang berbeda.
   Perbaiki kode sesuai dengan pesan error yang tertera, lalu lakukan validasi ulang hingga aplikasi berjalan tanpa error.
