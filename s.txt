## LANGKAH 1 — PERSIAPAN XAMPP

1. Buka **XAMPP Control Panel**
2. Klik **Start** pada **Apache** → tunggu sampai hijau
3. Klik **Start** pada **MySQL** → tunggu sampai hijau
4. Buka folder `C:\xampp\htdocs\`
5. Buat folder baru: **`kasir_restoran`**
6. Di dalam `kasir_restoran`, buat folder: **`config`**, **`classes`**, **`views`**

```sql
CREATE TABLE pelanggan (
    idpelanggan INT AUTO_INCREMENT PRIMARY KEY,
    namapelanggan VARCHAR(100) NOT NULL,
    jeniskamin TINYINT(1) NOT NULL,
    nohp CHAR(13),
    alamat CHAR(95)

CREATE TABLE pesanan (
    idpesanan INT AUTO_INCREMENT PRIMARY KEY,
    idmenu INT,
```

### FILE 1 — `config/Database.php`

```php
<?php
class Database {
    private $host = "localhost";
    private $db_name = "db_kasir_restoran";
    private $username = "root";
    private $password = "";
    public $conn;

    public function getConnection() {
        $this->conn = null;
        try {
            $this->conn = new PDO("mysql:host=".$this->host.";dbname=".$this->db_name.";charset=utf8mb4", $this->username, $this->password);
            $this->conn->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
            $this->conn->setAttribute(PDO::ATTR_DEFAULT_FETCH_MODE, PDO::FETCH_ASSOC);
        } catch(PDOException $e) {
            die("Koneksi gagal: " . $e->getMessage());
        }
        return $this->conn;
    }
}
?>
```

```php
<?php
class User {
    private $conn;
    public $iduser, $namauser, $password, $role;

    public function __construct($db) { $this->conn = $db; }

    public function login() {
        $q = "SELECT iduser, namauser, role FROM user WHERE namauser=:u AND password=:p LIMIT 1";
        $s = $this->conn->prepare($q);
        $s->bindParam(':u', $this->namauser);
        $s->bindParam(':p', $this->password);
        $s->execute();
        if($s->rowCount() > 0) {
            $r = $s->fetch();
            $this->iduser = $r['iduser'];
            $this->role = $r['role'];
            return true;
        }
        return false;
    }
}
?>
```

```php
<?php
class Pesanan {
    private $conn;
    public $idpesanan, $idmenu, $idpelanggan, $jumlah, $iduser;

    public function __construct($db) { $this->conn = $db; }

    public function create() {
        $q = "INSERT INTO pesanan (idmenu, idpelanggan, jumlah, iduser) VALUES (:m, :p, :j, :u)";
        $s = $this->conn->prepare($q);
        return $s->execute([':m'=>$this->idmenu, ':p'=>$this->idpelanggan, ':j'=>$this->jumlah, ':u'=>$this->iduser]);
    }

    public function readAllWithDetails() {
        $q = "SELECT p.idpesanan, m.namamenu, m.harga, p.jumlah, pl.namapelanggan, u.namauser 
              FROM pesanan p
              JOIN menu m ON p.idmenu = m.idmenu
              JOIN pelanggan pl ON p.idpelanggan = pl.idpelanggan
              JOIN user u ON p.iduser = u.iduser
              ORDER BY p.idpesanan DESC";
        return $this->conn->query($q);
    }
}
?>
```

```php
<?php
class Transaksi {
    private $conn;
    public $idtransaksi, $idpesanan, $total, $bayar;

    public function __construct($db) { $this->conn = $db; }

    public function prosesTransaksi() {
        $q = "CALL ProsesTransaksi(:i, :t, :b)";
        $s = $this->conn->prepare($q);
        return $s->execute([':i'=>$this->idpesanan, ':t'=>$this->total, ':b'=>$this->bayar]);
    }

    public function readLaporan() {
        $q = "SELECT t.idtransaksi, m.namamenu, p.jumlah, t.total, t.bayar, pl.namapelanggan, u.namauser
              FROM transaksi t
              JOIN pesanan p ON t.idpesanan = p.idpesanan
              JOIN menu m ON p.idmenu = m.idmenu
              JOIN pelanggan pl ON p.idpelanggan = pl.idpelanggan
              JOIN user u ON p.iduser = u.iduser
              ORDER BY t.idtransaksi DESC";
        return $this->conn->query($q);
    }
}
?>
```

## LANGKAH 5 — CEK MASALAH UMUM

**Kalau muncul "Koneksi gagal: SQLSTATE[HY000] [1045]"**
→ MySQL Anda pakai password. Buka `config/Database.php`, ganti:
```php
private $password = "";
```
Jadi password MySQL Anda, misalnya:
```php
private $password = "root";
```

**Kalau muncul "Koneksi gagal: SQLSTATE[HY000] [1049] Unknown database"**
→ Database belum dibuat. Ulangi **Langkah 2**.

**Kalau muncul "Object not found" / 404**
→ Folder salah tempat. Pastikan ada di `C:\xampp\htdocs\kasir_restoran\` (huruf kecil semua, tanpa spasi).

**Kalau halaman putih kosong**
→ Buka `C:\xampp\php\php.ini`, cari `display_errors = Off`, ganti jadi `display_errors = On`. Restart Apache. Refresh halaman.

**Kalau login berhasil tapi blank putih**
→ Buka file `config/Database.php`, tambahkan di baris paling atas:
```php
<?php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```
Lalu refresh, akan muncul pesan error detail. Kirim ke saya errornya.
