Aplikasi Sistem Lelang Online berbasis  Laravel 11  dengan:
- Flow:  Register → Login → Pakai  (tanpa data dummy)
- 3 role: Administrator, Petugas, Masyarakat
-  6 Stored Procedure  (MySQL)
-  6 tabel  +  7 migration  +  1 seeder 

---

| Komponen | Teknologi |
|----------|-----------|
| Framework | Laravel 11 |
| Database | MySQL + Stored Procedure |
| Frontend | Blade + CSS Custom |
| Server | PHP Development Server |

---



| Fitur | Administrator | Petugas | Masyarakat |
|-------|:-------------:|:-------:|:----------:|
| Registrasi | ✅ | ✅ | ✅ |
| Login/Logout | ✅ | ✅ | ✅ |
| CRUD Barang | ✅ | ✅ | ❌ |
| Buat Lelang | ✅ | ✅ | ❌ |
| Buka/Tutup Lelang | ✅ | ✅ | ❌ |
| Penawaran | ❌ | ❌ | ✅ |
| Laporan | ✅ | ✅ | ❌ |

---


1. `sp_register_petugas` — Daftar petugas/admin
2. `sp_register_masyarakat` — Daftar masyarakat
3. `sp_buka_lelang` — Buka lelang
4. `sp_tutup_lelang` — Tutup lelang + set pemenang
5. `sp_tambah_penawaran` — Tambah penawaran + validasi
6. `sp_laporan_lelang` — Laporan per periode

--


```cmd
composer create-project laravel/laravel lelang-online
cd lelang-online
# Edit .env → DB_DATABASE=lelang_online
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Buka: http://localhost:8000 →  Register dulu  → Login
