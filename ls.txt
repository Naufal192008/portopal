#### 5️⃣ PERBAIKAN

**1. Buat middleware:**
```cmd
php artisan make:middleware RoleMiddleware
```

**2. Isi `app/Http/Middleware/RoleMiddleware.php`:**
```php
<?php
namespace App\Http\Middleware;
use Closure;
use Illuminate\Http\Request;

class RoleMiddleware
{
    public function handle(Request $request, Closure $next, ...$roles)
    {
        if (!auth()->check()) {
            return redirect()->route('login');
        }
        if (!in_array(auth()->user()->role, $roles)) {
            abort(403, 'Akses ditolak. Role Anda tidak diizinkan.');
        }
        return $next($request);
    }
}
```

**3. Daftarkan di `bootstrap/app.php`:**
```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->alias([
        'role' => \App\Http\Middleware\RoleMiddleware::class,
    ]);
})
```

**4. Update `routes/web.php`:**
```php
Route::middleware('role:administrator,waiter')->group(function () {
    Route::resource('menu', MenuController::class);
    Route::resource('orders', OrderController::class);
});
```

#### 5️⃣ PERBAIKAN

**Update SP di migration:**
```php
DB::unprepared("
    DROP PROCEDURE IF EXISTS sp_complete_transaction;
    CREATE PROCEDURE sp_complete_transaction(
        IN p_order_id INT,
        IN p_user_id INT,
        IN p_payment_method VARCHAR(20),
        IN p_amount_paid DECIMAL(12,2)
    )
    BEGIN
        DECLARE v_total DECIMAL(12,2);
        DECLARE v_change DECIMAL(12,2);
        DECLARE v_table_id INT;

        SELECT total, table_id INTO v_total, v_table_id FROM orders WHERE id = p_order_id;
        SET v_change = p_amount_paid - v_total;

        UPDATE orders SET status = 'paid', updated_at = NOW() WHERE id = p_order_id;
```

### 🔴 ERROR #12: Total Order Tidak Ter-Update

#### 1️⃣ IDENTIFIKASI BUG

Setelah tambah item ke order, kolom `total` di tabel `orders` tetap **0**.

**Jenis Bug:** Missing aggregate update

---

#### 2️⃣ LOKASI ERROR

- **SP:** `sp_add_order_item`

---

#### 3️⃣ ANALISIS ERROR

**Penyebab:**
- SP `sp_add_order_item` insert item, tapi **tidak update total** di tabel `orders`
- Perlu agregasi `SUM(subtotal) + tax`

---

#### 4️⃣ MEMBUKTIKAN ANALISIS

**Bukti — Cek data:**
```sql
SELECT id, subtotal, tax, total FROM orders WHERE id = 1;
```
**Hasil:** `1 | 0 | 0 | 0` ❌
✅ **Analisis BENAR** — total tidak ter-update.

---

#### 5️⃣ PERBAIKAN

**Update SP:**
```php
CREATE PROCEDURE sp_add_order_item(
    IN p_order_id INT,
    IN p_menu_item_id INT,
    IN p_quantity INT,
    IN p_note TEXT
)
BEGIN
    DECLARE v_price DECIMAL(12,2);
    DECLARE v_subtotal DECIMAL(12,2);
    DECLARE v_total_subtotal DECIMAL(12,2);
    DECLARE v_tax DECIMAL(12,2);
    DECLARE v_total DECIMAL(12,2);

    SELECT price INTO v_price FROM menu_items WHERE id = p_menu_item_id;
    SET v_subtotal = v_price * p_quantity;

    INSERT INTO order_items (order_id, menu_item_id, quantity, price_per_unit, subtotal, note, created_at, updated_at)
    VALUES (p_order_id, p_menu_item_id, p_quantity, v_price, v_subtotal, p_note, NOW(), NOW());

    -- ✅ UPDATE TOTAL
    SELECT IFNULL(SUM(subtotal), 0) INTO v_total_subtotal FROM order_items WHERE order_id = p_order_id;
    SET v_tax = v_total_subtotal * 0.10;
    SET v_total = v_total_subtotal + v_tax;

    UPDATE orders
    SET subtotal = v_total_subtotal, tax = v_tax, total = v_total, updated_at = NOW()
    WHERE id = p_order_id;
END
```
